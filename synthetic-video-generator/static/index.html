1. Фото и дефекты

Перетащите фото сюда
Можно вместе с JSON / XML
JPEG, PNG или WebP · до 40 МБ / 50 Мп

Введите название и протяните рамку на фото. Можно отметить несколько дефектов.

Перетащите JSON / XML сюда или на фото

XML: name → класс, bndbox → рамка. Размеры XML должны совпадать с фото. Координаты сохраняются без сдвига −1.

Ввести координаты вручную / формат JSON

Формат: {"objects":[{"label":"дефект","bbox":[120,340,250,480]}]}. Координаты после учёта EXIF-поворота.

2. Параметры видео

Глубина оценивается локально. Дефекты сохраняются из исходного фото; открывающийся фон восстанавливается и исключается из разметки. Первичная обработка может занять несколько минут.

Фиксация почти всего фото на 2 с как отдельной точки маршрута. Фото должно быть близко к 16:9 (видно не менее 90% площади).

Короткие плавные эпизоды во время движения и зума. 0% отключает эффект. На остановках изображение восстанавливается.

Seed задаёт порядок проходов, направления, зум, повороты и длительность манёвров. Тот же seed воспроизводит маршрут при тех же настройках и разметке.

Добавьте фото и хотя бы одну рамку.

MP4 без нарисованных рамок. ZIP содержит покадровый JSONL, метаданные и ключевые кадры. Экспорт выполняется локально; время зависит от разрешения, числа дефектов и GPU.
