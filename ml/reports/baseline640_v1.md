## Модель, данные и воспроизводимость

- YOLO11n, предобученные `yolo11n.pt`; один класс: ID 0, `czjyz_ps`.
- Цель: локальное повреждение керамики, а не целый изолятор.
- `yolo-czjyz-ps-v1`: 3109 / 389 / 389 изображений train / val / test;
  3259 / 405 / 412 объектов соответственно.
- 25 из 25 эпох, imgsz=640, фактический batch=16, seed=20261103.
- AdamW, lr0=0.001, AMP, deterministic=True, save_period=5.
- Tesla T4; Ultralytics 8.3.228; Python 3.13.16;
  PyTorch 2.11.0+cu130, CUDA build 13.0 — по сохранённому окружению Colab.
- Конфигурация: `ml/configs/baseline_czjyz_ps_v1.json`;
  запуск: `ml/train.py`, `ml/notebooks/colab_baseline_v1.ipynb`.
- Исходный запуск использовал незакоммиченный код на HEAD
  `1cd0eff8d4bd562f9b8ac7e13fd587cb3c271632`. Новая ветка сохраняет этот
  код постфактум; SHA нового коммита не является историческим SHA обучения.
  Хеши всех восьми файлов frozen training bundle, включая план split,
  совпали с текущими локальными файлами при проверке сохранности.
  При добавлении в Git существующая настройка окончаний строк нормализует
  `ml/train.py` из CRLF в LF: содержимое после нормализации совпадает,
  но SHA256 Git blob отличается. Оба хеша и причина сохранены в реестре;
  исходный bundle и рабочий файл не переписывались.
- Локальный manifest и Colab manifest имеют разные SHA256 вследствие
  различий метаданных/путей. Их семантическое соответствие проверено
  в исходном аудите; их нельзя считать побайтово одинаковыми файлами.

## Реальные результаты — validation

Источник: сохранённый `validation_metrics.json`, повторный inference не выполнялся.

| Метрика | Значение |
|---|---:|
| Precision | 78.60% |
| Recall | 69.83% |
| mAP50 | 75.71% |
| mAP50–95 | 37.13% |

Эти Precision/Recall относятся к validation-процедуре Ultralytics,
а не автоматически к рабочему conf=0.25. Отдельная сохранённая диагностика
при conf=0.25 и matching IoU=0.5: 299 TP / 116 FP / 106 FN,
Precision=72.05%, Recall=73.83%. FP/FN считаются относительно доступной GT.

Лучшая эпоха по CSV mAP50–95 — 25 (0.37104); отдельная validation best.pt
дала 0.371289. Разница процедур не скрывается. Losses снижались, явного
обвала validation не обнаружено. Разрыв mAP50 и mAP50–95 указывает на
ограниченную точность локализации. Для GT с короткой стороной <16 px
после resize до 640 найдено 10/36 объектов (27.8%).

Полный исходный анализ, графики и TP/FP/FN-примеры остаются локально в
`ml/runs/baseline640_v1/analysis.md` и `analysis_figures/`.

## Ограничения

Датасет преимущественно положительный, проверенных негативов нет.
Остаточный риск похожих сцен между split сохраняется. Семантический аудит
был выборочным (48 изображений), не полным. Есть ошибки локализации,
конкурирующие рамки и пропуски маленьких дефектов. Точность на новых
видео и полная задержка worker не измерены. Эта фиксация baseline
не включает интеграцию, повторное обучение или исправления YOLOv8s.
